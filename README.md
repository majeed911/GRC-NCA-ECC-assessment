# GRC Compliance Assessment — NCA ECC Gap Analysis

A complete Governance, Risk, and Compliance (GRC) assessment project simulating a real-world NCA ECC (Essential Cybersecurity Controls) engagement for a fictional SaaS company, **TechNova Solutions**.

This project was built to develop and demonstrate practical GRC skills: control assessment, risk analysis, remediation planning, and security policy writing — aligned with Saudi Arabia's National Cybersecurity Authority (NCA) Essential Cybersecurity Controls framework.

## Scenario

**Organization:** TechNova Solutions (fictional)
**Sector:** SaaS — HR management platform for SMEs
**Size:** 80 employees, hybrid work model
**Infrastructure:** Web application hosted on AWS, customer database containing employee PII (salary, ID data)

## Scope

Two NCA ECC domains were assessed:

- **Domain 1 — Cybersecurity Governance** (Controls 1-1, 1-2, 1-3, 1-4, 1-5, 1-8)
- **Domain 2 — Cybersecurity Defence**, specifically **Control 2-2: Identity and Access Management**

## Methodology

1. **Gap Assessment** — Evaluated the fictional organization's current state against each applicable NCA ECC control, documenting evidence and identifying gaps
2. **Risk Register** — Translated each gap into a formal risk entry, scored using a Likelihood × Impact matrix
3. **Remediation Plan** — Defined concrete corrective actions, owners, and timelines, prioritized by risk severity
4. **Access Control Policy** — Authored a full internal security policy addressing the identified access control gaps

## Framework Reference

This assessment references the National Cybersecurity Authority's **Essential Cybersecurity Controls (ECC)**, Saudi Arabia's mandatory cybersecurity baseline. Control numbering follows the official ECC domain/subdomain structure (e.g., Control 2-2 — Identity and Access Management).
